  TROUBLESHOOTING FLOWCHART
═══════════════════════════════════════════════════════════════════════

  Problem: Can't push to GitHub
  ↓
  Solution: 
  • Install GitHub CLI: cli.github.com
  • Or create Personal Access Token
  • Use token as password


  Problem: Netlify build fails
  ↓
  Check build logs → Find error
  ↓
  Common fixes:
  • Wrong build command
  • Wrong publish directory
  • Missing dependencies


  Problem: Domain not working
  ↓
  Wait 1 hour for DNS propagation
  ↓
  Still not working?
  • Double-check DNS records
  • Use whatsmydns.net to verify
  • Contact domain registrar


  Problem: Sitemap 404
  ↓
  Wait 10 minutes (CDN cache)
  ↓
  Clear browser cache (Ctrl+Shift+R)
  ↓
  Still 404?
  • Dynamic fallback will catch it
  • Check console for errors
  • Tell me the exact error


  Problem: Google won't accept sitemap
  ↓
  Wait 24-48 hours
  ↓
  Still error?
  • Check Content-Type header
  • Validate XML at xml-sitemaps.com
  • Try resubmitting
